# CodeHub

CodeHub ta'lim platformasi to'liq monoreposi (Frontend va Backend).

## Papkalar Strukturasi

```text
CodeHub/
├── Frontend/      # React, Vite, TypeScript, TailwindCSS, Playwright
└── Backend/       # Node.js, Express.js, TypeScript REST API
```

---

## Tezkor Ishga Tushirish

### 1. Backend

```bash
cd Backend
npm install
npm run dev
```
Backend `http://localhost:4000` manzilida ishga tushadi.

### 2. Frontend

Yangi terminal oynasida:
```bash
cd Frontend
npm run dev
```
Frontend `http://localhost:5173` manzilida ochiladi va API so'rovlarni avtomatik `http://localhost:4000` ga yo'naltiradi (proxy).
